RPi-PSU-enclosure.sc - SolidCraft design file
=============================================

The source of this enclosure is a parametric design made in SolidCraft,
a free, open-source 3D CAD application (Apache-2.0 license) by Tangency Labs.

  Website:        https://solidcraft.io
  Download:       https://github.com/tangency-labs/solidcraft/releases/latest
                  (Windows, macOS and Linux builds)
  Documentation:  https://docs.solidcraft.io

Version
-------
Made with SolidCraft 0.41.0
File format: solidcraft/55

Open the file with SolidCraft 0.41.0 or newer. Older versions cannot read
its file format.

Keep these two lines current. When you save the file with a newer
SolidCraft, write its version and the new file format here.
scripts/check_cad_info.py runs on every pull request and fails when the
file format in the .sc file no longer matches this file.

What is in the file
-------------------
- The base and the lid with their full feature history and named parameters.
- A configuration table with one row per lid variant (Raspberry Pi 4 or 5,
  logo, fan size). Activate a row to switch the model.
- Reference models of the Raspberry Pi 5, the Mean Well RS-25-5, the screws
  and the heat-set inserts, for checking fits. They are not printed.

No SolidCraft?
--------------
The ../step folder has every part as a STEP file, which opens in most CAD
programs (FreeCAD, Fusion, Onshape, SolidWorks and others). STEP files have
no parameters or history.

See ../docs/customizing.md for the parameters and the export script.
